# Nimitt Ajmera Portfolio

This repository holds the source for [Nimitt Ajmera](https://nimittajmera.com/)'s personal portfolio website. All of the web assets live in the `public/` directory and can be deployed on any static hosting service such as Firebase Hosting or GitHub Pages.

## Preview locally

You can serve the site locally with Python:

```bash
python3 -m http.server 8080 -d public
```

Then visit <http://localhost:8080/> in your browser.
